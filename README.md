# Dashboard เชิงเล่าเรื่อง: รถมือสองกับโอกาสของตลาดอะไหล่ยานยนต์
67160206 Kittitas Kaewsai

Data Storytelling Dashboard ที่วิเคราะห์ข้อมูลประกาศขายรถจักรยานยนต์มือสอง (1,061 คัน) เพื่อชี้โอกาสของอุตสาหกรรมชิ้นส่วนและอะไหล่ยานยนต์ (Aftermarket)

## โครงสร้างโปรเจกต์
```
.
├── index.html          # Dashboard (เปิดได้เลย ไม่ต้องติดตั้งอะไร)
├── data/
│   └── BIKE_DETAILS.csv  # ข้อมูลที่ใช้
├── MEMBERS.md          # รายชื่อกลุ่ม
└── README.md
```

## วิธีใช้งาน
1. ดาวน์โหลดหรือ clone repository
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์
3. (ทางเลือก) เผยแพร่ผ่าน GitHub Pages: Settings → Pages → Branch `main` / root

## เรื่องที่เล่า (Storyline)
1. รถที่หมุนเวียนในตลาดมีอายุมาก (ครึ่งหนึ่งอายุ ≥ 5 ปี)
2. ระยะทางสะสมบอกรอบการเปลี่ยนอะไหล่ (ราว 20% วิ่งเกิน 50,000 กม.)
3. มูลค่ารถลดเร็ว เจ้าของจึงเลือกซ่อมด้วยอะไหล่คุ้มค่า
4. จัดลำดับแบรนด์ที่ควรเน้นอะไหล่ (Hero, Bajaj, Honda)
5. ข้อเสนอแนะเชิงธุรกิจสำหรับผู้ผลิตและผู้จำหน่ายอะไหล่

## ข้อมูลและวิธีคำนวณ
- แหล่งข้อมูล: `data/BIKE_DETAILS.csv` คอลัมน์ name, selling_price, year, seller_type, owner, km_driven, ex_showroom_price
- อายุรถ = 2020 − ปีผลิต (2020 คือปีล่าสุดในข้อมูล)
- แบรนด์ = คำแรกของชื่อรุ่น (Royal Enfield นับเป็นแบรนด์เดียว)
- กลุ่มอะไหล่ต้องการสูง = อายุ ≥ 5 ปี หรือ วิ่ง ≥ 50,000 กม.
- % มูลค่าคงเหลือ = selling_price ÷ ex_showroom_price (ใช้เฉพาะแถวที่มีราคา ex-showroom ซึ่งว่างอยู่ 41%)

## ข้อจำกัด
ข้อมูลเป็นรถมือสองจากประกาศขาย ไม่ใช่ยอดขายอะไหล่โดยตรง จึงเป็นการประเมินความต้องการทางอ้อม ผู้ขายส่วนใหญ่เป็นบุคคลทั่วไป (Individual) และราคาเป็นสกุลเงินตามต้นฉบับของชุดข้อมูล
